# 🛡️ Security Policy

## 📦 Supported Versions

To ensure the safety of your bot and server, please ensure you are using a supported version. We actively provide security updates and patches for the versions listed below.

| Version | Status | Description |
| :--- | :--- | :--- |
| **v5.2.6** | ✅ **Supported** | Beta Version (Newest Features) |
| **v5.2.0** | ✅ **Supported** | Refurbished / Stable Version |
| **v5.1.2** | ⚠️ **Vulnerable** | Buggy / Known issues; update recommended |
| **v5.1.0** | ❌ **End of Life** | No longer supported |
| **< v5.0** | ❌ **End of Life** | Outdated / Insecure |

> **Note:** If you are running a version marked with ❌ or ⚠️, please upgrade immediately to the latest version to prevent crashes and security exploits.

---

## 🐛 Reporting a Vulnerability

We take the security of **Eren-Yeager-ADV** seriously. If you discover a security vulnerability or a critical bug (e.g., database leaks, admin bypass), please do **NOT** open a public issue.

Instead, please report it privately via:
1.  **Telegram:** Contact the bot owner or support group.
2.  **GitHub:** Use the "Report a vulnerability" tab if enabled on this repository.

We will attempt to respond within 48 hours and release a patch as soon as possible.

---

## ⚡ Keeping Secure

To maintain the security of your instance:
1.  **Fork this Repository:** Do not just download the files. Fork the repo so you can pull updates easily.
2.  **Update Plugins:** We frequently release updated plugins to fix external API changes. Check the repository or support channel regularly.
3.  **Protect Configs:** Never share your `config.env` or `session string` with anyone.
